# Recoding *Introduction to Mediation, Moderation, and Conditional Process Analysis*

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.18390882.svg)](https://doi.org/10.5281/zenodo.18390882)

Andrew Hayes's *Introduction to Mediation, Moderation, and Conditional Process Analysis*  text has become a staple in social science graduate education. The [third edition](http://afhayes.com/introduction-to-mediation-moderation-and-conditional-process-analysis.html) came out recently, and this project is based on the second edition, from 2018. All three editions of his text have been from a frequentist OLS perspective. This project is an effort to connect his work with the Bayesian paradigm. Herein I refit his models with my favorite **R** package for Bayesian regression, Bürkner's [**brms**](https://github.com/paul-buerkner/brms) use the packages from the [**tidyverse**](https://www.tidyverse.org) to visualization and data manipulation.
